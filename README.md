# 🧬 TVP-Bioinformatics

Computational biology and bioinformatics resources for the TVP laboratory (Toni Vidal-Puig group).

We develop and maintain analytical frameworks for studying metabolic disease, adipose tissue biology, and multi-omics data integration, with a focus on disease progression, cellular state transitions, and translational interpretation.

---

## 🔬 Core Research Areas

- **Metabolic disease trajectories**  
  Continuous and discrete modelling of disease progression (e.g. MASLD)

- **Adipose tissue biology**  
  Brown and white adipocyte differentiation and signalling networks

- **Multi-omics integration**  
  Transcriptomics, single-cell RNA-seq, and systems-level analysis

- **Computational modelling of cellular states**  
  Machine learning and statistical frameworks for biological state inference

---

## 📊 Featured Projects

### MASLD disease trajectory modelling
Continuous trajectory inference and machine learning-based stratification of metabolic disease progression.

### Adipocyte signalling (BMP4 / BMP9 axis)
Analysis of signalling pathways regulating adipogenesis and metabolic programming.

### MHPS framework
Computational tools and analysis workflows for internal TVP datasets and modelling approaches.

### MHPS Explorer
Interactive tool for exploring MHPS-derived datasets and visualisations.

---

## 📁 Repository Principles

We follow a simple set of principles:

- **Reproducibility first** — analyses should be rerunnable end-to-end  
- **Separation of data and code** — raw data is never modified  
- **Modularity** — pipelines are reusable across projects  
- **Transparency** — key decisions and parameters are documented
